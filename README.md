# Company Management System – Backend

## Overview
This project is a backend API for managing companies, departments, employees, projects, and employee performance reviews. It includes authentication, role-based access control, and state transitions for workflows.

## Features
1. **User Management**: Signup, login, and role-based access (Admin, Manager, Employee).
2. **Company Management**: CRUD operations for companies.
3. **Department Management**: CRUD operations for departments.
4. **Employee Management**: CRUD operations for employees with role-based access.
5. **Project Management**: CRUD operations for projects with employee assignments.
6. **Performance Reviews**: Workflow for employee performance reviews.
